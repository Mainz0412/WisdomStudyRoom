# 🎯 智慧自习室 - 启动指南

## 📋 快速启动

### 方法 1: 一键启动（推荐）

#### macOS / Linux：
```bash
# 1. 进入项目目录
cd /path/to/Wisdom-Study-Room-master

# 2. 给启动脚本权限
chmod +x start.sh

# 3. 运行启动脚本
./start.sh
```

#### Windows：
```bash
# 双击运行 start.bat
start.bat
```

**脚本会自动：**
- ✅ 检查 Java、npm、MySQL 环境
- ✅ 构建后端 JAR（如果需要）
- ✅ 启动后端服务（http://localhost:8080）
- ✅ 等待后端就绪
- ✅ 安装前端依赖（如果需要）
- ✅ 启动前端服务（http://localhost:8081）
- ✅ 显示访问地址和账号信息

---

### 方法 2: Docker 方式（最简单）

```bash
# 1. 确保 Docker Desktop 已安装并运行

# 2. 进入项目目录
cd /path/to/Wisdom-Study-Room-master

# 3. 启动所有服务
docker-compose up -d

# 4. 查看状态
docker-compose ps

# 5. 查看日志（可选）
docker-compose logs -f
```

**这会自动：**
- 拉取和启动 MySQL 容器
- 初始化数据库
- 构建并启动后端容器
- 启动前端容器
- 所有服务在单个命令中启动

**停止服务：**
```bash
docker-compose down
```

---

### 方法 3: 手动启动（不推荐，仅用于调试）

#### 步骤 1: 启动后端

```bash
# 在第一个终端窗口
cd /path/to/Wisdom-Study-Room-master

# 方式 A: 使用 Maven
mvn clean spring-boot:run

# 方式 B: 使用预构建的 JAR
java -jar target/demo-0.0.1-SNAPSHOT.jar
```

等待看到：`Started DemoApplication in X.XXX seconds`

#### 步骤 2: 启动前端

```bash
# 在第二个终端窗口
cd /path/to/Wisdom-Study-Room-master/vue_project

# 安装依赖（首次运行）
npm install

# 启动前端
npm run serve
```

等待看到：`App running at: http://localhost:8081/`

## ⚙️ 配置文件

### 后端配置
文件位置：`src/main/resources/application.properties`

```properties
server.port=8080
spring.datasource.url=jdbc:mysql://localhost:3306/wisdom_study_room?useUnicode=true&characterEncoding=utf-8
spring.datasource.username=wisdom
spring.datasource.password=wisdom_study_room
```

### 前端配置
文件位置：`vue_project/vue.config.js`

```javascript
devServer: {
  port: 8081,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
      pathRewrite: { '^/api': '' }
    }
  }
}
```

## 🛠️ 故障排除

### 问题 1: 后端启动失败

**错误**: `Access denied for user 'wisdom'@'localhost'`
```bash
# 重新初始化数据库
mysql -u root -p < init-database.sql
```

**错误**: `Port 8080 is already in use`
```bash
# 修改 application.properties 中的端口
server.port=8089
```

### 问题 2: 前端启动失败

**错误**: `npm: command not found`
- 请重新安装 Node.js

**错误**: `npm 依赖安装很慢`
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install
```

### 问题 3: 前后端通信失败

**检查清单**：
- [ ] 后端是否启动成功（访问 http://localhost:8080）
- [ ] 前端是否启动成功（访问 http://localhost:8081）
- [ ] vue.config.js 中的代理配置是否正确
- [ ] MySQL 是否正在运行
- [ ] 浏览器控制台是否有错误（按 F12）

**解决方案**：
```bash
# 清空浏览器缓存
# 重新启动所有服务
./start.sh  # 或 docker-compose down && docker-compose up
```

### 问题 4: MySQL 连接失败

```bash
# 检查 MySQL 是否运行
mysql -u wisdom -p -e "SELECT 1;"

# 如果使用 Docker Compose，MySQL 已包含
docker-compose up mysql
```

## 📊 性能优化

cd vue_project

# 增加数据库连接池

## 📝 常用命令

### 启动
```bash
# 一键启动所有服务
./start.sh                    # Linux/Mac
start.bat                     # Windows
docker-compose up -d          # Docker

# 手动启动（分开）
mvn spring-boot:run          # 后端
npm run serve                # 前端
```

### 停止
```bash
Ctrl+C                        # 停止一键脚本
docker-compose down           # 停止 Docker
```

### 查看日志
```bash
# 后端日志
tail -f backend.log

# 前端日志
tail -f vue_project/frontend.log

# Docker 日志
docker-compose logs -f backend
docker-compose logs -f frontend
```

### 清理
```bash
# 清理后端构建
mvn clean

# 清理前端依赖
rm -rf vue_project/node_modules

# Docker 清理
docker-compose down -v
```
